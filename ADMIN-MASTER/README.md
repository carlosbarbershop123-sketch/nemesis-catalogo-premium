# ADMIN MASTER

O painel de manutenção permanente é o repositório GitHub autenticado do proprietário:
https://github.com/carlosbarbershop123-sketch/nemesis-catalogo-premium

O catálogo público é servido pela branch `gh-pages`. Para mudar o número de destino
dos pedidos, edite `checkout-config.js` nessa branch. O GitHub Pages republica o
arquivo após o commit. Esse número fica visível no código público.

Preços e conteúdo ainda estão no `index.html`; ajustes feitos apenas no navegador
não alteram o site visto pelos clientes. Uma futura interface administrativa com
senha e alterações globais exige backend e autenticação reais.
